# Review of service export, hook commands and log streams

Baseline `3482373` on `review/beta4-followup`. The review traced the CLI, SCM lifecycle, process and hook launch, environment restoration, registry and GUI settings, logging and rotation, and the associated test and packaging entry points.

- [ ] **Keep NTFS log streams distinct.** The identity check strips a sole `:$DATA` as if it were a type annotation. Preserve the stream name when no type was supplied. Test both spellings of the named stream, the default stream, and actual stdout/stderr writes. [Windows stream naming](https://learn.microsoft.com/en-us/windows/win32/fileio/file-streams)
- [ ] **Quote the executable chosen in the hook browser.** A hook field holds a complete command line. Quote a selected filename before setting the field, preserve the existing command on cancellation or overflow, and test the resulting saved command. [CreateProcessW](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createprocessw)
- [ ] **Reject dump commands that exceed the shell limit.** Measure each complete escaped install or set line before writing it. Report an error for overlong lines and test the 8,191-character boundary, including command prefixes and optional arguments. [Windows command prompt limits](https://learn.microsoft.com/en-us/troubleshoot/windows-client/shell-experience/command-line-string-limitation)
- [ ] **Validate service keys at creation and clone export.** The existing length check allows slash and backslash in a clone target, yielding a script that cannot install it. Validate new keys before generating output or creating a service, and preserve display-name lookup for existing services. [CreateServiceW](https://learn.microsoft.com/en-us/windows/win32/api/winsvc/nf-winsvc-createservicew)
- [ ] **Verify the implementation.** Review the final diff, run the Windows x86/x64 Debug and Release matrix, static analysis, x64 AddressSanitizer, package verification, and the Windows 11 service and upgrade suites.
