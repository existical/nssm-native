# Review of startup settings, environment export and console output

The baseline was `032a954` with the five fixes from the preceding review in the working tree. The review covered service control and startup, the CLI and GUI configuration paths, process and hook execution, registry and environment handling, stream output, and the build and test entry points. All 37 x64 Release tests passed before this implementation.

## Findings and implementation plan

- [ ] **High — A rejected delayed startup request can enable a disabled service.** A fixture recorded the successful switch to automatic before the delayed-start write failed. Share one startup update path between the CLI and editor. Read the existing delayed flag, prepare the requested flag before changing the base configuration, and restore it if the base update fails. Preserve compatibility with managers that lack delayed startup. Test both failure orders and verify the setting on a real disposable service. [Windows delayed-start contract](https://learn.microsoft.com/en-us/windows/win32/api/winsvc/ns-winsvc-service_delayed_auto_start_info)
- [ ] **Medium — Driver startup queries report the wrong mode.** Windows reported boot start for the disk and TCP/IP drivers, while NSSM returned automatic with exit code zero. Handle boot and system modes in the read-only CLI path, keep them out of the service editor, and test both against SCM configuration.
- [ ] **Medium — Duplicate environment keys change meaning across a dump and replay.** The named getter returned the first assignment while the child received the last. Replaying the emitted operations also changed an intermediate variable from `first` to `last`. Preserve assignment order and duplicates in export, honor the command length limit, and return the last assignment on a named query. Test case variants and a dependent assignment.
- [ ] **Medium — Overlapping CLI commands leave the console on the wrong code page.** Two real NSSM listings on a private console starting at code page 437 left it at 65001. Preserve Unicode console and UTF-8 redirected output without changing the shared console setting. Repeat the overlapping-process check and validate non-ASCII output.
- [ ] Run the four Windows configurations, focused regressions, static analysis, sanitizer and disposable Windows service checks. Record the results and review the final changes.
