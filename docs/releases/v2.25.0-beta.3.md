# NSSM Native 2.25.0-beta.3

This prerelease fixes cases where NSSM could lose concurrent log writes, report a startup timeout for a running service, or change application settings during a backup or an unrelated GUI edit.

For 64-bit Windows, download the x64 Release ZIP. Choose x86 Release for a 32-bit installation. Each binary ZIP includes matching debugging symbols. Verify the ZIP against `RELEASE-ASSETS-SHA256SUMS.txt` and run `nssm.exe version` to confirm the version and architecture. The executables are unsigned. [x64 Release download](https://github.com/existical/nssm-native/releases/download/v2.25.0-beta.3/nssm-native-v2.25.0-beta.3-x64-Release.zip)

## Changes for operators

- In append mode, independent writers can share a log. Copy/truncate checks the archived bytes before clearing the active file. If the data changed or a competing writer still has the file open, NSSM preserves the active data. Comparing large logs adds disk I/O.
- Startup reports progress during configured offline rotation delays. Services handle early application exits and can start when optional power notifications are unavailable.
- Headless dumps preserve UTF-8 output, registry string types and deliberately empty replacement environments. Long launch arguments survive the configuration round trip. GUI edits preserve a working directory derived from the executable at startup. Use this beta's CLI when replaying its exports.
- Named service removal honors delegated rights. Install, edit and removal dialogs reject oversized service names. Hooks running under service accounts receive the configured display name. Hook-reset and delayed-start failures are reported to the caller.

## Upgrade and rollback

Back up the current executable and export the service configuration. Stop the service, confirm its application has exited and replace the executable at the same path. Check startup, application readiness, logs and shutdown under the configured service account. Keep the previous executable and configuration available for rollback. [Upgrade rehearsal](https://github.com/existical/nssm-native/blob/v2.25.0-beta.3/docs/releases/upgrade-rehearsal.md)
