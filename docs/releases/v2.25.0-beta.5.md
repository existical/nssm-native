# NSSM Native 2.25.0-beta.5

This prerelease addresses cases where a failed service edit could change startup behavior and an exported configuration could produce a different environment after replay.

For 64-bit Windows, use the x64 Release ZIP. Use the x86 Release ZIP for 32-bit Windows. The binary ZIPs include matching debugging symbols. The executables are unsigned. Verify the ZIP with `RELEASE-ASSETS-SHA256SUMS.txt`, then run `nssm.exe version` to check the version and architecture. [Download x64 Release](https://github.com/existical/nssm-native/releases/download/v2.25.0-beta.5/nssm-native-v2.25.0-beta.5-x64-Release.zip)

## Changes since beta.4

- NSSM validates dependencies before changing the service and submits dependencies, startup type, account and display name together. Delayed-start edits preserve the base startup mode if Windows rejects the delayed flag.
- Startup queries distinguish boot-start and system-start drivers. Overlapping CLI commands preserve the console code page, including when output is redirected.
- Configuration export retains duplicate environment keys and their assignment order. Named queries return the last assignment. Export rejects commands that exceed the command processor's 8,191-character limit.
- The editor preserves untouched priority settings and protects hook commands when a field cannot be refreshed. Selecting a hook executable whose path contains spaces now quotes the path.
- Wrapped console applications honor `AppNoConsole` with redirected output. NSSM reports unexpected logging-pipe read failures even when online rotation is disabled and keeps wrapper-owned log handles private.
- Service supervision checks process identity during inspection, reports stable SCM status without stale progress hints and bounds waits during hook shutdown.

Before replacing a deployed wrapper, record its version and checksum, back up its configuration, and verify rollback with the application. [Upgrade and rollback rehearsal](https://github.com/existical/nssm-native/blob/v2.25.0-beta.5/docs/releases/upgrade-rehearsal.md)
